# FeedMyPixel — About design brief

**For:** [claude.ai/design](https://claude.ai/design). Builds on `brief-global.md` (tokens, type,
header, footer). Mirrors stat's system (`~/Projects/status/stat-ui/src/lib/styles`). Deliver the
**About page** as self-contained HTML + CSS, light theme primary (dark a bonus), desktop + mobile.

## Goal

The fuller "about Ben" — the home page carries a short teaser; this is the depth. It should make a
hiring lead confident and a fellow developer interested, without becoming a CV dump.

## Content to shape

- **Who Ben is.** Senior contract full-stack software engineer, 20+ years. Multi-disciplined:
  full-stack build, web design, architecture, dev-ops/infra, accessibility, design systems. Arts +
  media degree background → design sensibility alongside engineering.
- **How he works.** *Simple, well-made, quality.* Small, disciplined teams; resilient,
  progressively-enhanced, accessible products with strong test coverage; great UX. Translates
  product/business/user needs into robust solutions.
- **Pedigree.** Selected clients — Guardian, BBC, HMRC/GDS, DEFRA, Wayfair, M&S, MoJ — and the
  current WhiskyInvestDirect SvelteKit rebuild. Summary-level, not a full work history.
- **His own products.** Pipes (live) and stat (coming) — the products Ben is building himself.
- **Human note (light).** St Albans; outside work: gardening, cooking, cycling, DIY/restoring —
  a maker. Keep it brief and genuine, a single warm touch, not a hobby list.
- **Contact / hire CTA** + newsletter signup.

## Notes

- Tone: confident, calm, authentic — the builder-scratching-own-itch voice, not agency gloss.
- Don't dead-end: clear next step (hire / read the blog / subscribe).
- Layout split between home-teaser and this page is **your call** — propose what reads best.

## Deliver

The About page, light theme (dark optional), desktop + mobile, annotated against the global tokens.
